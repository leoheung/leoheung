## What I'm building now

- **[GitKleen](https://github.com/leoheung/GitKleen)** — A light, native git client for macOS, Windows and Linux, made for coding with agents: the window refreshes as the agent works, you stage what's right and hand the rest back (forked from MyGit and reworked, down to Linux arm64 builds).
- **[go-patterns](https://github.com/leoheung/go-patterns)** — A collection of Go concurrency patterns and data structures, still growing.
